## 🐳 Run Using Docker

Clone the repository:

```bash
git clone https://github.com/Mahek-319/mahek-portfolio.git
```

Navigate to the project directory:

```bash
cd mahek-portfolio
```

Build the Docker image:

```bash
docker build -t mahek-portfolio:v1 .
```

Run the container:

```bash
docker run -d \
  --name mahek-portfolio-container \
  -p 8080:80 \
  mahek-portfolio:v1
```

Open in your browser:

```text
http://localhost:8080
```

## ☁️ AWS Deployment

The portfolio is deployed on an AWS EC2 Ubuntu instance using Docker and Nginx.

**Deployment workflow:**

1. Develop the portfolio using HTML and CSS.
2. Create a Dockerfile using Nginx Alpine.
3. Build a Docker image.
4. Run the application inside a Docker container.
5. Configure AWS Security Group inbound access.
6. Access the website through the EC2 public IP.
